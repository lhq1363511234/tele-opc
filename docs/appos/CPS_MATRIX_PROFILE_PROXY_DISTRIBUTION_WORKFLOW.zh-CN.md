# CPS 矩阵 Profile / Proxy / 分发工作流

本文定义 Tele-OPC 在 CPS 短剧矩阵业务里的 Profile、Proxy、账号报白、素材采集、剪辑和自动分发流程。

核心原则：

- 用户只填 CloakBrowser `Profile 名称`，不填 Profile ID。
- 登录只在第一次接入账号、新增账号、session 失效时由用户手动完成。
- 报白只在第一次绑定账号/短剧、新增账号、新增短剧绑定时由用户手动完成。
- 系统不自动登录、不处理验证码、不自动报白、不自动获取账号资料。
- 系统负责读取飞书表、复用已登录 Profile、检测 Proxy、采集并下载原片、分析剪辑、自动发布。
- 数据回收暂时不做。

## 1. 飞书表结构

### 1.1 Profile 表

一行表示一个 CloakBrowser Profile，只管理浏览器环境和 Proxy，不塞平台账号详情。

建议字段：

| 字段 | 说明 |
| --- | --- |
| Profile 名称 | 用户在 CloakBrowser Manager 里看到的名称，必须唯一 |
| 用途 | 素材采集 / 分发 / 两者 |
| Proxy | 用户手动填写，该 Profile 使用的代理 |
| cleanip 分数 | 系统检测后写回 |
| Proxy 状态 | 未检测 / 合格 / 不合格 |
| 登录状态 | 未登录 / 已登录 / 登录失效 |
| 最近检测时间 | cleanip 最近一次检测时间 |
| 备注 | 人工备注 |

规则：

- 用户不需要知道 Profile ID。
- 系统运行时调用 CloakBrowser Manager `/api/profiles`，按 `Profile 名称` 查实际 ID。
- 如果找不到 Profile，流程停止并提示用户。
- 如果 Profile 名称重复，流程停止并提示用户改唯一名称。
- 分发前必须用该 Profile 打开 `https://cleanip.io/` 检测 Proxy 纯净度。
- cleanip 分数 `>= 90` 才允许继续登录态复用和分发。
- cleanip 分数 `< 90` 时，停止该 Profile 相关流程，飞书提示用户更换原生住宅 Proxy。

### 1.2 平台账号表

一行表示一个平台账号，绑定到某个 Profile 名称。

建议字段：

| 字段 | 说明 |
| --- | --- |
| 平台 | MoboBoost / 北斗智影 / Facebook / TikTok / YouTube / Instagram |
| 账号ID / 频道ID | 用户手动填写 |
| 账号昵称 | 用户手动填写 |
| 主页链接 | 用户手动填写 |
| 绑定 Profile 名称 | 关联 Profile 表里的 Profile 名称 |
| 当前短剧名 | 当前要绑定/分发的短剧名 |
| 当前短剧链接 | 当前短剧的短剧链接 |
| 当前 App 链接 | 当前短剧的 App 链接 |
| 报白状态 | 未报白 / 已报白 / 不需要 / 失败 |
| 登录状态 | 未登录 / 已登录 / 登录失效 |
| 是否启用 | 是 / 否 |
| 备注 | 人工备注 |

规则：

- 账号资料全部由用户自己填。
- 系统不自动获取账号 ID、账号昵称、主页链接。
- 同平台多个账号不能绑定同一个 Proxy/Profile。
- 分发时先查平台账号表，再反查绑定 Profile。
- 如果账号未启用、登录状态不是 `已登录`、报白状态不允许发布，流程停止。

## 2. 人工边界

### 2.1 登录

以下情况由用户自己登录：

- 第一次接入某个素材平台账号时。
- 第一次接入某个分发平台账号时。
- 新增素材平台账号时。
- 新增 Facebook / TikTok / YouTube / Instagram 等分发账号时。
- session/cookie 失效时。
- 遇到验证码、二次验证、短信验证、邮箱验证、设备验证、风控验证时。

登录完成后：

- 用户在飞书 `Profile 表` 填 `Profile 名称`、`用途`、`Proxy`。
- 用户在飞书 `平台账号表` 填账号资料和绑定 Profile 名称。
- 用户把对应登录状态标记为 `已登录`。

系统行为：

- 后续自动化只复用已登录 Profile 的 session/cookie。
- 系统不保存平台账号密码。
- 系统不尝试自动登录。
- 如果检测到未登录或 session 失效，流程停止，飞书提示用户手动处理。

### 2.2 报白 / 账号报备

以下情况由用户自己报白：

- 第一次给某个平台账号绑定某个短剧时。
- 新增平台账号时。
- 新增短剧绑定到某个账号时。
- 平台提示需要重新报白或补充资料时。

报白资料由用户自己填写：

- 账号 ID / 频道 ID
- 账号昵称
- 主页链接
- 当前短剧名
- 当前短剧链接
- 当前 App 链接
- 平台要求的其他资料

系统行为：

- 系统不自动填写报白表单。
- 系统不半自动获取账号资料。
- 系统不自动提交报白。
- 系统不判断报白是否真实成功，只读取飞书表里的 `报白状态`。
- 如果 `报白状态` 不是 `已报白` 或 `不需要`，系统不进入该账号的自动发布流程。

## 3. 完整业务流程

### 3.1 用户准备 Profile

用户在 CloakBrowser Manager 创建 Profile，配置 Proxy，并手动登录对应平台。

示例 Profile 名称：

- `北斗智影`
- `MoboBoost`
- `facebook-01`
- `tiktok-01`

然后在飞书 `Profile 表` 填：

- Profile 名称
- 用途
- Proxy
- 登录状态
- 备注

### 3.2 用户准备平台账号资料

用户在飞书 `平台账号表` 填平台账号资料。

示例：

| 平台 | 账号昵称 | 主页链接 | 绑定 Profile 名称 | 当前短剧名 | 当前短剧链接 | 当前 App 链接 | 报白状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Facebook | Page A | https://facebook.com/page-a | facebook-01 | The Lost Heiress Came Back | https://... | https://... | 已报白 |
| TikTok | TK A | https://tiktok.com/@tk-a | tiktok-01 | The Lost Heiress Came Back | https://... | https://... | 已报白 |

### 3.3 发起选剧

用户从飞书或 Telegram 发起选剧。

流程：

1. 选择素材平台：MoboBoost/CDReader 或北斗智影。
2. 选择来源平台：MoboReels / KalosTV / ShortMax 等。
3. 选择具体短剧。

### 3.4 n8n 调已登录 Profile 采集素材

n8n 读取 `Profile 表`，找到用途包含 `素材采集` 的 Profile 名称。

执行：

1. 按 Profile 名称调用 CloakBrowser Manager `/api/profiles` 查 Profile ID。
2. 启动对应 Profile。
3. 打开素材平台页面。
4. 检查是否已登录。

异常：

- 找不到 Profile：停止流程，提示用户检查 Profile 名称。
- Profile 名称重复：停止流程，提示用户改唯一名称。
- 未登录或 session 失效：停止流程，提示用户手动登录该 Profile。

### 3.5 采集素材并下载原片

脚本采集：

- 剧名
- 短剧 ID
- 来源平台
- 分佣比例
- 付费起始集
- 总集数
- 封面
- 短剧链接
- App 链接
- 推广文案
- 口令

然后下载原片。

要求：

- 选中剧后必须下载原片。
- 不允许只采链接不下载视频。
- 下载失败就停止后续剪辑。
- 下载失败原因写回飞书。

常见失败原因：

- 未生成资源。
- 账号无权限。
- 报白未完成。
- 页面提示账号报备。
- 下载按钮不可用。
- 浏览器下载失败。
- session 失效。

### 3.6 写入源素材表

素材采集和下载完成后写入 `源素材表`。

如果原片下载完成：

- `原片下载状态 = 已完成`
- `本地素材目录 = xxx`
- `已下载集数 = 1,2,3...`
- `状态 = 待分析`

如果原片下载失败：

- `原片下载状态 = 失败`
- `状态 = 失败`
- `失败原因 = xxx`

### 3.7 媒体预处理

对每一集原片执行：

- ffprobe
- 英文 ASR
- 生成英文 SRT 字幕
- 截图采样
- 黑屏检测
- 静音检测
- 对白密度
- 时长、比例、分辨率分析

结果写入 `媒体分析表`。

### 3.8 Dify 剪辑策划

n8n 调 Dify，输入：

- 剧名
- 每集字幕
- 每集截图
- 视频时长
- 剧情文本
- 剪辑规则
- 风控要求

Dify 输出至少三套策略：

- 高燃冲突版
- 悬念反转版
- 解说引导版

每套策略包含：

- hook
- timeline
- 英文字幕策略
- 发布标题
- 发布文案
- 标签
- 二创处理要求
- 版权风险提示

### 3.9 capcut-mate / CapCut 剪辑

根据 Dify 策略生成草稿或成片。

处理要求：

- 英文字幕
- 9:16
- 轻微缩放/裁切
- 重构图
- 调色
- 节奏强化
- 顶部钩子字幕
- 多版本输出

结果写入 `剪辑版本表`。

### 3.10 用户选择分发账号

用户在飞书选择今天要发哪些平台账号。

示例：

- Facebook：Page A
- TikTok：TK A

系统从 `平台账号表` 找到绑定 Profile 名称，并读取：

- 当前短剧名
- 当前短剧链接
- 当前 App 链接
- 报白状态
- 登录状态
- 是否启用

### 3.11 分发前 cleanip 检测

每个待发布账号都先检查绑定 Profile 的 Proxy。

流程：

1. 启动绑定 Profile。
2. 打开 `https://cleanip.io/`。
3. 读取分数。
4. 写回 `Profile 表`。

判断：

- `>= 90`：允许分发。
- `< 90`：停止该账号分发，飞书提示用户更换原生住宅 Proxy。

### 3.12 自动分发

Proxy 合格后，系统打开对应平台发布页面。

自动执行：

- 上传剪好的视频。
- 填标题。
- 填发布文案。
- 填短剧链接 / App 链接 / 口令。
- 选择必要配置。
- 自动点击发布。

本阶段不做人审，不停在发布按钮前。

### 3.13 发布结果写回

发布完成后写入 `发布记录表`。

记录：

- 剧名
- 剪辑版本
- 平台
- 账号昵称
- Profile 名称
- cleanip 分数
- 发布时间
- 发布状态
- 发布链接
- 失败原因

### 3.14 数据回收

暂时不做。

播放、点赞、评论、点击、订单、佣金等数据回收以后再加。

## 4. 自动化准入规则

账号进入自动分发前必须满足：

- Profile 名称能解析到唯一 CloakBrowser Profile。
- Profile 登录状态为 `已登录`。
- 平台账号绑定了 Profile 名称。
- 平台账号登录状态为 `已登录`。
- 平台账号 `是否启用 = 是`。
- 平台账号当前短剧名、当前短剧链接、当前 App 链接已填写。
- 报白状态为 `已报白` 或 `不需要`。
- cleanip 分数 `>= 90`。
- 剪辑版本状态可发布。

任一条件不满足，流程停止并写明失败原因。

## 5. 系统不做的事

- 不创建平台账号。
- 不登录账号。
- 不保存平台账号密码。
- 不处理验证码、2FA、短信、邮箱、风控验证。
- 不自动报白。
- 不自动填写报白表单。
- 不自动获取账号 ID、主页链接、账号昵称。
- 不自动判断报白是否真实成功。
- 暂不做播放、点击、订单、佣金等数据回收。
